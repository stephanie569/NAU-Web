# Fabrica® Studio — NAU Site

A Fabrica-inspired creative studio portfolio built with Next.js, inspired by the [Fabrica Framer template](https://www.framer.com/community/marketplace/templates/fabrica/) by Anatolii Dmitrienko.

## About this project

This is a **code recreation** of the Fabrica template's design language — monochrome aesthetic, large typography, grid layout, and all core pages. It is **not** the official Framer template files.

To use the **official Fabrica template** in Framer:

1. [Purchase Fabrica ($129)](https://www.framer.com/community/marketplace/templates/fabrica/) on the Framer Marketplace
2. Click the remix link you receive after purchase
3. The template copies into your Framer workspace for visual editing

## Pages

- **Home** — Hero, services, stats, clients, projects, testimonials, blog preview, FAQ
- **Studio** — About, team, careers
- **Projects** — Filterable project grid with case study detail pages
- **Blog** — Article listing and detail pages
- **Contact** — Contact form and info
- **Legal** — Privacy Policy, Terms of Service

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize for NAU

Edit `src/lib/data.ts` to update branding, content, projects, and team info.

## Using Framer MCP (optional)

If you remix the official template in Framer:

1. Open your Framer project
2. Press `Cmd+K` and search for **MCP**
3. Open the MCP plugin to connect Cursor
4. Use the Framer MCP tools to edit the live Framer project or export React components

## Tech stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 4
- Framer Motion
